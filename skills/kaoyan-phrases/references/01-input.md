# 01 · 输入

用户会给：考研真题的原文、题干、选项；一篇英文文章或新闻片段；中英混合的笔记、聊天记录、语音转写；已经列好的词组清单。

中文作上下文，提取对象是其中的英文搭配。

## 三种入口

| 入口 | 做法 |
| --- | --- |
| 对话里粘贴的文本 | 存进 `%TEMP%\kaoyan-phrases\` 的 txt，脚本跑完清空 |
| `.txt` / `.md` | 直接交给脚本读 |
| `.docx` | 直接交给脚本，内存里抽取段落与表格，中间 txt 留在临时目录 |

`.txt` 先按 UTF-8（含 BOM）读，失败再按 GBK（gb18030）读；两种都不匹配时提示另存为 UTF-8，不会抛 traceback。

## 长文本

超过 2000 词时，先报预计条目数，问用户要全量还是先处理第一节。
