# 05 · 质量

## 释义

- 给**考研语境下最常见的一到两个义项**：account for 几乎只考「解释」和「占比例」。
- 中文、简短；义项之间用分号：`解释；占（比例）`。
- 类型写在释义后的括号里：`遵守；遵从（动词短语）`。常用类型：动词短语、介词短语、名词搭配、形容词搭配、习语、固定表达、连接短语。
- 音标、词源、语法讲解留给语法笔记。
- 上下文定不了义时取最常见义，并在「提示」里注明「按上下文取 X 义」。

## 边界情况

- **输入已是词组清单**：逐条补全——补释义、补原文例句、合并重复，按同一格式输出。
- **中文占多数、英文零星**：处理英文部分；英文凑不成搭配时给出这几个词的释义并标「未构成搭配」。
- **原文与题干选项并存**：一起处理，例句末尾标 `[原文]` / `[题干]` / `[选项]`；真题的考点常落在选项搭配上。
- **中文句意、提分点里的搭配**：不算英文出现，也不据此反推英文词组；确有价值就用 `--add` 入表，提示里写清出处。
- **中文笔记提到、正文里没有的搭配**：另起一行说明「笔记提到 X，正文未出现，未收录」，例句照正文。
- **同一搭配多次出现**：一条，频次累加（脚本自动处理）。
