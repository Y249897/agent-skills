# 04 · 交付

交付物三个：`kaoyan-cards.csv`、`kaoyan-vocab.xlsx`、`kaoyan-phrases.docx`。

## CSV 规格

五列，表头固定：

```csv
正面,背面,词头,频次,提示
```

- `正面`：词组本身，Anki「基础」卡片第一字段。
- `背面`：释义，后接括号里的类型；材料里有原句就接上例句，中文句号隔开。
- `词头`：归并用的首词（account for → account），也决定排序。
- `频次`：累计出现次数。
- `提示`：一句最容易被忽略的点，没有就留空。
- 字段含逗号或引号时整段用英文双引号包住，内部引号写两个；编码 UTF-8 带 BOM。

## Word 规格

`kaoyan-phrases.docx` 是给人看的学习讲义，由脚本生成：

- 标题「考研高频固定搭配」，下一行统计：总条数、频次合计、高频线、材料来源。
- **高频段**：频次 ≥ 高频线的条目，行首 `★`、词组加粗深绿、黄色底纹，附频次与释义。
- **全表**：四列表格（词组 / 频次 / 类型 / 释义），按词头归并；高频行同样带 `★` 与深绿加粗。
- 高频线：频次前 10% 分位，且不低于 3 次。
- 结尾一行注明频次为累计口径、`★` 为高频标记。

## 交付四步

1. **贴内容**：回复里给出这次 CSV 全文（代码块标 `csv`）；超过 30 行贴前 30 行并写明「共 N 条，完整内容见文件」，再把本次新增/更新的行单独贴一遍，否则它们在总表末尾看不见。
2. **标位置**：三行绝对路径，用行内代码包住。
3. **给卡片**：用 present 呈现三个文件，xlsx 为主、docx 次之、csv 最后。
4. **报数字**：新增几条、更新几条、总条数、高频几条、Top 15 变化，一句一行。

## 自检

```powershell
python -B "$SKILL\tools\check_outputs.py"
```

核对 CSV 与总表的条数、顺序、频次、字段，UTF-8 BOM，词头规则，「处理记录」的累计（每行总条数 = 截至该行的「新增 − 删除」累计，末行 = 当前条数），以及 Word 表格行数与 `★` 高频条数。退出码 0 再交付。

## 原文件原则

交付物始终是这三个文件，每次更新在原文件上进行：不生成 `-2026-11-20` 这类日期文件，不在别处复制一套。

## 收尾

```powershell
$cwd = (Get-Location).Path
Get-ChildItem $cwd
Get-ChildItem (Join-Path $cwd "kaoyan-phrases")
```

当前目录应见 `kaoyan-phrases\`，里面是三个产出文件。

临时文件写在 `%TEMP%\kaoyan-phrases\`，交付后清空；脚本用 `python -B` 运行，不产生 `__pycache__`。
